# 排卵模型第一版

这是一个可直接本地运行或部署的 HTML + FastAPI 决策支持工具。V1 使用两类证据：

1. 东阿现有摸排数据中“当前卵泡直径 → 首次确认 CL”的统计规律；
2. 已发表驴繁殖研究中的成熟阈值、德州驴卵泡生长速度和排卵前参考直径。

系统将“预计排卵窗口”和“预计确认 CL 时间”分开显示。后者受摸排频率影响，不等于真实排卵时刻。

## 偏早的单点输出

为满足东阿“可以提前、尽量避免晚报”的安排需求，网页和Streamlit页面优先显示对应窗口最早时间：

- 成熟预测时间取成熟窗口下界；
- 排卵预测时间取最终排卵窗口下界（包含个体增长和促排修正）；
- 主要结果直接显示北京时间的具体日期时刻，窗口仅供趋势图和接口参考；已观察到CL时不输出未来预测。

API调用方请使用新增的 `maturity_prediction.time` 和 `ovulation_prediction.time`，策略字段 `point_estimate_policy` 为 `window_lower_bound`。原有 `maturity_center`、`ovulation_center` 保留原来的中心值以兼容已有系统，不作为偏早业务输出。

例如默认东阿/德州参数、当前35 mm、无历史和促排信息时，成熟单点输出由中心值11.1小时改为8.1小时，排卵单点输出由55.5小时改为40.2小时。

**取下界不保证一定早于真实时间。** 当前窗口来自生长公式及CL记录约束，没有经过真实成熟或排卵时刻的覆盖率校准；项目内11.01小时MAE仅针对首次确认CL。详细字段、示例和后续验证口径见 [偏早输出说明.md](偏早输出说明.md)。

## V1 输入

- 当前摸排时间；
- 左、右卵泡状态：30～60 mm数值（含边界）、SF（小于30 mm）或CL；
- 可选：上一次最大卵泡及时间，用于修正个体生长速度；

当前左右侧及上次记录中的毫米数值均限定在30～60 mm。SF和CL的`value_mm`必须为空；上次仅有SF时不提供上次记录。左右均为SF时不计算时间预测。网页、接口和模型核心执行同一范围限制，越界接口请求返回HTTP 422。

网页固定采用东阿/德州驴参数，配种建议按本场主要的鲜精人工授精场景估计。不需要选择配种方案或填写提前量。

天气、温度和湿度在 V1 不进入公式。当前数据没有逐次摸排对应的气象记录，现有文献也不能提供可直接迁移到本场的小时级作用系数。

## 鲜精配种建议（服务1.4.0）

根据本场导出数据，默认给出偏早的鲜精配种安排：

```text
剩余配种小时数 = max(0, 偏早排卵剩余小时数 - 24)
建议配种时间 = 本次摸排时间 + 剩余配种小时数
```

不将达到37 mm成熟参考的时间作为配种硬门槛。保留“偏早排卵前24小时”的参考安排。大量预约及部分登记配种时间填为00:00，疑似仅记录日期，本次没有用这些值拟合新的小时级提前量或取整规则。

页面直接显示成熟、排卵、配种的具体日期时刻，不显示“约多少小时/天”，也不输出下次超声时间。接口直接读取`maturity_prediction.time`、`ovulation_prediction.time`和`breeding_recommendation.time`。配种方式和提前量仍无需录入。

例如默认参数、当前35 mm、摸排时间为`2026-11-18 08:00`、无历史记录时，成熟时间显示`2026-11-18 16:06`，排卵时间显示`2026-11-20 00:12`，建议配种时间显示`2026-11-19 00:12`。这是将原有预测转换为日期时刻，计算公式未变。

这是鲜精常规安排，不是已验证的最优受胎时间，不能保证绝不晚报。执行前确认发情、卵泡及子宫状态，是否追配需复查后决定。特殊促排/冻精情况不能直接套用。API显式传入其他方式或提前量时保留上一版兼容行为；显式促排仍提示需要具体方案。

本次分析去重后共7810条摸排记录，其中1148条为30～60 mm且尚未确认排卵的数值记录。原始Excel保持不变，生长参数及成熟、排卵窗口未重新训练。数据口径、配对限制及回顾性对比见 [鲜精配种数据分析.md](鲜精配种数据分析.md)，文献依据见 [配种时间依据.md](配种时间依据.md)。

## 推荐：启动 HTML 预测页面和接口

页面和接口使用同一个端口。在项目目录执行：

```bash
python -m pip install -r requirements-api.txt && python -m uvicorn api:app --host 127.0.0.1 --port 8001
```

浏览器打开 `http://127.0.0.1:8001/` 使用预测页面，打开 `http://127.0.0.1:8001/docs` 查看接口文档。预测页面包括：

- 左右卵泡和可选历史摸排录入；
- 直接以具体日期时刻显示的成熟、排卵单点预测；
- 无需额外选择方案的鲜精配种建议；
- 实测点、中心预测线、快慢生长范围与排卵窗口图；
- 可拖动或自动播放的时间推演。

8001 端口被占用时可换为 8002：

```bash
python -m uvicorn api:app --host 127.0.0.1 --port 8002
```

训练参数已保存在 `models/v1_model.json`，所以日常使用不需要再次训练。

原有 Streamlit 页面仍保留在 `app.py`，如有需要可单独启动，但推荐使用新的 HTML 页面。

## 提供给外部公司的HTTP接口

项目同时包含FastAPI接口。接口使用说明、请求字段、鉴权和Docker部署方法见 `API_README.md`。

```bash
python -m pip install -r requirements-api.txt && python -m uvicorn api:app --host 0.0.0.0 --port 8000
```

启动后访问 `http://127.0.0.1:8000/` 使用网页，访问 `http://127.0.0.1:8000/docs` 查看自动接口文档。对外部署时必须设置 `DONKEY_API_KEY` 并通过HTTPS或公司API网关开放。


## V1 边界

- V1 是生产摸排与配种安排的决策支持工具，不代替兽医超声判断。
- 当前排卵标签是区间标签：排卵发生在最后一次见到优势卵泡与首次确认 CL 之间。
- 对 30、35、40 mm 附近的输入，本场数据支持较强；远离这些值时属于外推。
- 当出现 CL 时，系统只报告“已经进入排卵后状态”，不会继续预测未来排卵。
